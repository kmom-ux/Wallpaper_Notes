# Wallpaper_Notes — 前端样式文档

> 版本：v0.3  
> 创建日期：2026-05-15  
> 最后更新：2026-05-20（同步 v0.3 修复 — QTabBar 背景修复 + 移除全局 content/editor 冗余 + 清理未用字段）  
> 用途：修改 `theme.json` 时，快速对照界面元素 → 容器 → 选择器 → 可改参数。避免"改 A 发现 B 也受影响"。

---

## 1. 界面分层总览

```
┌─ WallpaperWindow ──────────────────────────────────────────────┐
│  ① 窗口整体（圆角 + 边框，背景通过 alpha 半透显示桌面壁纸）      │
│                                                                │
│  ┌── QTabWidget ──────────────────────────────────────────────┐│
│  │ ② 顶部标签栏（背景色来自 tab_bar.background_color）          ││
│  │ ③ [标签1]  ④ [标签2(蓝色底线)]  [标签3]  ⑤ [+]            ││
│  └────────────────────────────────────────────────────────────┘│
│                                                                │
│  ┌── QStackedWidget / 内容区 ─────────────────────────────────┐│
│  │ ⑥ 内容显示区（QTextBrowser + 可选玻璃/文字辉光/磨砂噪声）     ││
│  │   ⑦ 渲染后的文字（Markdown → HTML CSS）                     ││
│  │                                                             ││
│  │   —— 编辑模式（双击/Enter 切换） ——                          ││
│  │ ⑧ 编辑输入框（QPlainTextEdit + 可选文字辉光）                 ││
│  └────────────────────────────────────────────────────────────┘│
│                                                                │
│  ⑨ 滚动条（内容溢出时出现）                                     │
└────────────────────────────────────────────────────────────────┘
```

## 2. 元素 → 容器 → 选择器 → 可改参数

### ① 窗口整体

| 项 | 内容 |
|----|------|
| **你看到的** | 窗口的圆角、边框线；背景通过 WA_TranslucentBackground + 半透色彩（rgba）透出桌面壁纸 |
| **Qt 容器** | `WallpaperWindow(QWidget)` |
| **QSS 选择器** | `WallpaperWindow` |
| **生成函数** | `ui_components.py` → `generate_window_qss()` |
| **theme.json 路径** | `window.*` |
| **圆角实现** | 通过 `setMask(QRegion)` 的 QPainterPath.addRoundedRect 实现，不是 QSS border-radius（WA_TranslucentBackground 下 Windows 分层窗口中不生效） |

**可改参数：**

| theme.json 字段 | QSS 输出 | 默认值 |
|----------------|---------|--------|
| `window.background_color` | `background-color` | `rgba(255,255,255,0.85)` |
| `window.border_radius` | setMask 圆角 | `12` |
| `window.border_width` | `border-width` | `1` |
| `window.border_color` | `border-color` | `rgba(200,200,200,0.5)` |

**注意：** 背景透明度由 `background_color` 的 alpha 通道控制，不再使用 `setWindowOpacity`。圆角通过 `setMask` 实现而非 QSS。

---

### ② 顶部标签栏背景

| 项 | 内容 |
|----|------|
| **你看到的** | 标签页底部的灰色横条（标签文字背景） |
| **Qt 容器** | `QTabBar`（标签按钮所在区域） |
| **QSS 选择器** | `QTabBar`（单独的背景色）、`QTabWidget::pane`（固定透明） |
| **生成函数** | `ui_components.py` → `generate_tab_bar_qss()` |
| **theme.json 路径** | `tab_bar.background_color` |

**可改参数：**

| theme.json 字段 | QSS 输出 | 默认值 |
|----------------|---------|--------|
| `tab_bar.background_color` | `QTabBar { background-color }` | `rgba(245,245,245,0.9)` |

**修复说明（v0.3）：** `tab_bar.background_color` 现在控制的是 **QTabBar 本身**（标签按钮行），不再是 QTabWidget::pane（内容面板）。QTabWidget::pane 固定为透明，不再占用此配置。这意味着之前"调了背景色但只看到内容面板变色"的问题已经修复，现在标签栏背景可以与内容面板独立。

### ⑤ "+" 按钮

| 项 | 内容 |
|----|------|
| **你看到的** | 标签栏最右侧的加号按钮，用于新建便签 |
| **Qt 容器** | `QPushButton`（嵌入式，setParent(tabBar) + move() 定位） |

**当前状态：** 不可单独定制样式。如需定制，需在代码中给按钮设置 `objectName`，再添加对应 QSS 选择器。

### ⑥ 内容显示区（QStackedWidget）

| 项 | 内容 |
|----|------|
| **你看到的** | 便签正文的显示区域（渲染后的 Markdown）和其背景/边框 |
| **Qt 容器** | `QStackedWidget`（整体）+ `QTextBrowser`（内部 index 0） |
| **QSS 选择器** | `QStackedWidget`（整体边框 + 玻璃背景色）、`QTextBrowser`（独立 setStyleSheet） |
| **生成函数** | `ui_components.py` → `generate_content_qss()`（viewer）、`_build_glass_qss()`（玻璃效果 QStackedWidget 层） |
| **theme.json 路径** | `content.*` |

**可改参数（QStackedWidget 整体）：**

| theme.json 字段 | QSS 输出 | 默认值 |
|----------------|---------|--------|
| `content.pane_border_color` | `QStackedWidget { border-color }` | `rgba(200,200,200,0.5)` |
| `content.pane_border_width` | `QStackedWidget { border-width }` | `1` |
| `content.pane_border_radius` | `QStackedWidget { border-radius }`（仅下圆角，上圆角=0） | `4` |
| `content.enable_glass` | `_build_glass_qss()` 生成对角线渐变半透 CSS | `false` |
| `content.glass_opacity` | 渐变背景的 alpha 最大值 | `0.10` |
| `content.enable_frost` | 是否显示 FrostedNoiseWidget 噪点覆盖层 | `false` |
| `content.frost_intensity` | 噪点灰度扩散范围 | `0.20` |
| `content.frost_grain` | 噪点颗粒等级（1=小/2=中/3=大） | `1` |

**可改参数（QTextBrowser — viewer）：**

| theme.json 字段 | QSS 输出 | 默认值 |
|----------------|---------|--------|
| `content.background_color` | `background-color` | `transparent` |
| `content.text_color` | `color` | `#333333` |
| `content.font_family` | `font-family` | `Microsoft YaHei` |
| `content.font_size` | `font-size` | `16` |
| `content.padding_h` | `padding-left / padding-right` | `16` |
| `content.padding_v` | `padding-top / padding-bottom` | `16` |
| `content.enable_glow` | viewer.viewport().setGraphicsEffect(TextGlowEffect) | `false` |

**注意：** QTextBrowser 背景设置为 `transparent`，透出 QStackedWidget 的边框/玻璃背景色。文字辉光通过自定义 `TextGlowEffect(QGraphicsEffect)` 实现（box blur 缩小→放大模拟发光）。

### ⑦ Markdown 文字渲染样式

| 项 | 内容 |
|----|------|
| **你看到的** | 内容区中的标题、正文、引用块、列表等文本样式 |
| **Qt 容器** | `QTextBrowser` 的 `document` |
| **渲染方式** | HTML CSS（不是 QSS）— 由 renderer.py 生成完整的 `<html><head><style>...</style></head><body>...</body></html>` |
| **生成函数** | `renderer.py` → `build_css()` + `render()` |
| **theme.json 路径** | `content.*`（text_color, font_family, font_size, heading_color, heading_font_family, line_height） |

**可改参数（通过 renderer.py 的内联 CSS）：**

| theme.json 字段 | CSS | 默认值 |
|----------------|-----|--------|
| `content.font_family` | `body { font-family }` | `Microsoft YaHei` |
| `content.font_size` | `body { font-size }` | `16` |
| `content.text_color` | `body { color }` | `#333333` |
| `content.line_height` | `body { line-height }` | `1.6` |
| `content.heading_color` | `h1/h2/h3 { color }` | `#aaddff` |
| `content.heading_font_family` | `h1/h2/h3 { font-family }` | 同正文字体 |
| `content.padding_h / padding_v` | `body { padding }` | `16` |
| `content.background_color` | `body { background-color }` | `transparent`（从 viewer/stack 透出） |

这是一个**独立的渲染体系**，和 QSS 互不干扰。`renderer.py` 中的 `_CONTENT_CSS_TEMPLATE` 模板还包含引用块（blockquote）样式、代码样式、嵌套间距等。

## 3. QSS 注入路径总览

全局注入和局部覆盖的关系（v0.3 更新）：

```
theme.json
    ↓
ui_components.py (QSS 生成)
    │
    ├── build_global_qss() ───→ WallpaperWindow.setStyleSheet()
    │   ├── generate_window_qss()    → WallpaperWindow 背景/边框/圆角
    │   ├── generate_tab_bar_qss()   → QTabBar 背景 / QTabWidget::pane / QTabBar::tab
    │   └── generate_scrollbar_qss() → QScrollBar
    │
    └── 局部 setStyleSheet（在 window.py 中）：
        viewer.setStyleSheet(generate_content_qss(theme))    → QTextBrowser
        editor.setStyleSheet(generate_editor_qss(theme))     → QPlainTextEdit
        stack.setStyleSheet(border_qss + glass_qss)          → QStackedWidget

window.py 中 apply_theme() 也会重新应用所有局部覆盖。
```

**关键规则（v0.3）：**
- 全局 QSS 只包含窗口级和容器级样式（window / tab_bar / scrollbar），content/editor 完全由局部 `setStyleSheet` 控制。
- 各元素只在一个位置设置样式，没有冗余覆盖。
- `WallpaperWindow` 上的 `setStyleSheet` 也会影响子控件（QSS 继承），被子控件自己的 `setStyleSheet` 覆盖。
- QStackedWidget 的边框/玻璃 CSS 通过独立 `setStyleSheet` 注入，不在全局 QSS 中。

## 4. 当前不支持独立定制的元素

| 元素 | 原因 | 如需定制怎么做 |
|------|------|-------------|
| "+" 按钮 | 无 objectName，共用默认 QPushButton flat 样式 | 在 `window.py` 中给 `btn_add` 设置 `setObjectName("BtnAddNote")`，然后在 QSS 中用 `#BtnAddNote` 选择器 |
| FrostedNoiseWidget（磨砂噪点层） | 自定义 QWidget，使用 QPainter 绘制 | 可在 `FrostedNoiseWidget` 的 `paintEvent` 中调整绘制逻辑 |

## 5. theme.json 编写参考

修改 `theme.json` 时，上述参数表中的 **theme.json 字段** 就是你需要写的键名。例如想改选中标签的下划线颜色：

```json
{
  "tab_bar": {
    "active_indicator_color": "#FF6600"
  }
}
```

这会影响到 `QTabBar::tab:selected` 的蓝色下划线变为橙色。影响面仅限于该选择器，不会改动其他元素。

## 6. 当前 theme.json 结构（v0.3）

```json
{
  "window":           { /* ① 窗口整体 — background_color / border_radius / border */ },
  "tab_bar":          { /* ②③④ 标签栏全部 — background_color / font / padding / active_* */ },
  "content":          { /* ⑥⑦ 内容显示区 — font / color / padding / background / pane_border / glass / glow / frost */ },
  "editor":           { /* ⑧ 编辑框 — font / color / background / cursor */ },
  "scrollbar":        { /* ⑨ 滚动条 — width / handle / track */ }
}
```

**v0.3 移除的未使用字段：**
- `window.shadow` — 从未实现，已从 theme.json 中移除
- `tab_bar.height` — 从未在 QSS 中引用，已从 theme.json 中移除
- `hotkey.description` — 从未读取，已从 config.json 中移除
- `behavior.auto_save_interval_ms` — 从未读取，已从 config.json 中移除
