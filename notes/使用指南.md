# 📋 Wallpaper_Notes 使用指南

> 把便签贴在桌面上。写 Markdown = 贴便签。
> 不需要打开任何软件，退到桌面就能看。

---

## 🚀 基本操作

| 操作 | 方式 |
|------|------|
| **打开窗口** | 快捷键 `Ctrl+Alt+A` |
| **编辑便签** | 双击内容区域进入编辑模式 |
| **保存退出** | 再次双击 / 按 `Esc` |
| **新建便签** | 右键托盘图标 → 新增便签 |
| **删除便签** | 右键标签页 → 删除 |
| **重命名** | 右键标签页 → 重命名 |
| **设置** | 右键托盘图标 → 设置 |

---

## 🎨 样式自定义

**右键托盘图标 → 设置**，打开设置对话框。所有视觉效果均可实时调节、所见即所得。按「应用」即刻生效且不关闭对话框，方便反复调试。
ok：保存配置并退出设置
cancel：不保存配置并退出设置
apply：保存并应用配置但不退出设置，方便调试

### ⌨️ 全局快捷键

| 选项 | 说明 |
|------|------|
| **组合键** | Ctrl / Shift / Alt / Win（可多选） |
| **按键** | A-Z、0-9、F1-F12、Space、Tab、Escape、Enter、Backspace、Delete |
| **开机自启** | 勾选后随 Windows 启动，通过注册表 HKCU\Run 实现 |

> 默认：`Ctrl+Alt+A`

### 🪟 窗口样式

| 选项 | 说明 |
|------|------|
| **圆角** | 窗口整体圆角（0~50px），一般不用动 |

---

### 📑 标签栏

标签页部分的完整样式：

| 选项 | 说明 |
|------|------|
| **背景色** | 标签栏底色，滑块调透明度（0%=完全不透明，100%=全透，全透可能会导致点击穿透，即被系统视作为点击到了桌面上，而非便签上，这是Windows系统层的一些特性，计划在后续版本中进行修复） |
| **文字色** | 未选中标签的文字颜色（纯色） |
| **选中色** | 选中标签的文字颜色（纯色） |
| **指示色** | 选中标签底部的指示线颜色（纯色） |
| **字体** | 标签文字字体（下拉可选，支持自定义字体） |
| **字号** | 标签文字字号（8~40pt） |
| **上圆角** | 标签顶部圆角（0~30px） |

---

### 📝 内容区

便签正文内容的完整样式：

**基础**
| 选项 | 说明 |
|------|------|
| **背景色** | 内容区底色，滑块调透明度 |
| **文字色** | 正文文字颜色（纯色） |
| **标题色** | 标题（## / ### 等）文字颜色（纯色） |
| **标题字体** | 标题字体，可与正文字体不同 |
| **字体** | 正文字体 |
| **字号** | 正文字号（8~40pt） |

**内容框边框**
| 选项 | 说明 |
|------|------|
| **边框色** | 内容区域边框颜色，可带透明度 |
| **边框宽** | 边框宽度（0~10px） |
| **下圆角** | 内容框底部圆角（0~50px） |

**视觉效果**
| 选项 | 说明 |
|------|------|
| **玻璃效果** | 启用后内容区呈半透明玻璃质感，滑条调透明度（0.00~0.30） |
| **磨砂质感** | 启用后增加磨砂噪点纹理，滑条调强度（0.00~0.50），可选颗粒大小（小/中/大） |
| **文字发光** | 文字边缘淡淡发光效果 |

### 🔄 滚动条

### 🔤 字体管理

添加自定义 .ttf / .otf 字体到应用中：

1. 点击「添加字体...」按钮
2. 选择 `.ttf` 或 `.otf` 文件
3. 字体自动复制到 `fonts/` 目录，注册到应用
4. 所有字体下拉列表立即出现新字体
5. 重启应用后自动加载，不丢失

## 🤖 AI 自动写入

AI 可以直接往 `notes/` 写文件，桌面自动显示：

```bash
echo "## 今日灵感\n\n- 想到了一个好点子" > notes/灵感.md
```
