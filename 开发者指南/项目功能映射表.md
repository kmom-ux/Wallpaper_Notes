# 项目功能映射表

## 用途

需求/功能变更时，快速定位需要修改哪些文件、什么级别。
避免漏改、跑偏，减少「改完 A 发现 B 也得改」的回头路。

## 修改级别定义

| 级别 | 含义 | 典型场景 |
|------|------|---------|
| **类级** | 修改单个类的方法/属性，不影响外部接口 | 改样式、加过滤逻辑、调参数 |
| **文件级** | 修改多个文件的方法/接口，但模块职责不变 | 改回调签名、加新信号、调响应逻辑 |
| **架构级** | 新增/删除/合并模块，或模块间职责重分配 | 加新渲染引擎、拆出设置窗、换打包方案 |

---

## 文件清单

| 文件 | 职责 | 对外接口（被哪些模块引用） |
|------|------|---------------------------|
| `main.py` | 进程入口，创建 QApplication + App | 终端入口，无模块引用 |
| `app.py` | 总装：创建所有模块，连接信号，实现回调 | 仅被 main.py 调用 |
| `window.py` | 主窗口：标签栏、双层模式、拖拽缩放、层级切换、特效 | app.py（回调注入）/ renderer.py（render/css）/ ui_components.py（QSS） |
| `ui_components.py` | QSS 生成器 + 默认组件工厂 | 被 window.py 引用 |
| `renderer.py` | Markdown → HTML / CSS 生成（自定义解析器） | 被 window.py 引用 |
| `notes_manager.py` | 文件扫描 + watchdog 监听 + CRUD 信号 | 被 app.py 引用 |
| `hotkey.py` | 全局快捷键（Windows API + nativeEventFilter） | 被 app.py 引用 |
| `tray.py` | 系统托盘图标 + 右键菜单（含编辑入口） | 被 app.py 引用 |
| `config.py` | JSON 读写 + 窗口几何 + 注册表自启 | 被 app.py / window.py 引用 |
| `models.py` | 纯数据类（NoteInfo） | 被 notes_manager.py 引用 |
| `settings.py` | 设置对话框（快捷键 + 全部样式编辑 + 字体管理） | 被 app.py 引用（托盘菜单弹出） |

## 信号链路图（简化）

```
外部文件修改 → notes_manager (watchdog, 300ms debounce)
                   ├── note_changed → window.refresh_current_tab
                   ├── note_added   → window.add_tab
                   └── note_deleted → window.remove_tab

快捷键触发 → hotkey (RegisterHotKey + WM_HOTKEY + nativeEventFilter)
                └── activated → app (lambda) → window.bring_to_front_and_edit
                                  └── _set_topmost + _switch_edit + _set_foreground

托盘操作   → tray (右键菜单)
                ├── 显示/隐藏 → tray._on_toggle_show → window.show/hide
                ├── 进入编辑 → edit_requested → window.bring_to_front_and_edit
                ├── 设置     → settings_requested → app._on_settings_requested
                └── 退出     → exit_requested → app._quit

用户操作   → window (UI组件)
                ├── 双击/Enter → eventFilter → _switch_edit
                ├── Esc       → eventFilter → _save_and_switch_view → app._on_save_content
                ├── 三击      → eventFilter → _save_and_switch_view（编辑模式下）
                ├── ⊕ 按钮    → _on_add_clicked → app._on_create_note → notes.create
                ├── 右键菜单  → _on_tab_context_menu → app._on_delete/rename → notes.delete/rename
                ├── 标签拖拽  → eventFilter tab_drag → move() → config.set_window_geometry
                ├── 边缘缩放  → _detect_edges + _do_resize → config.set_window_geometry
                ├── 切换标签  → _on_tab_changed → 保存上一个编辑器内容
                └── 托盘双击  → tray._on_toggle_show → window.show/hide

设置对话框 → SettingsDialog
                ├── Apply → applied → app._apply_theme → theme.json + window.apply_theme()
                └── OK   → app._on_settings_requested 后续逻辑
                              ├── hotkey.rebind()
                              ├── app._apply_theme()
                              └── config.set_autostart()
```
