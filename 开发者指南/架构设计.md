## 2. 模块职责

### 2.1 UI 层

| 模块 | 职责 | 说明 |
|------|------|------|
| `window.py` | 主窗口框架 | 整体布局：顶部标签栏 + 中间内容区，窗口行为（桌面层/置顶/拖拽/缩放/双层切换），鼠标穿透（WM_NCHITTEST）、滚轮转发 |
| `ui_components.py` | UI 组件与样式 | 加载 theme.json 生成 QSS 样式，应用主题到所有控件。未来如果 QTabWidget 不满足需求，手搓自定义 TabBar 的改造点就在这里 |
| `settings.py` | 设置对话框 | 快捷��修改、全部 theme.json 字段编辑、字体管理、开机自启开关、实时预览 Apply |

**UI 与后端分离原则**：所有 UI 相关组件集中在 window.py + ui_components.py + settings.py，后端逻辑不直接操作 UI 元素。

### 2.2 后端层

| 模块 | 职责 |
|------|------|
| `app.py` | 应用主控，初始化所有模块，建立信号-槽连接，实现回调桥接 |
| `notes_manager.py` | 启动时扫描 `notes/` 下所有 `.md` 文件生成标签列表；运行时监听文件变化（新增/删除/修改，300ms 防抖），同步更新 |
| `config.py` | 读取/写入 config.json（功能配置）和 theme.json（样式配置），管理注册表自启 |
| `renderer.py` | 自定义 Markdown → HTML 转换器，结合 theme.json 生成内联 CSS |
| `tray.py` | 创建系统托盘图标，管理右键菜单（显示/隐藏/进入编辑/设置/退出） |
| `hotkey.py` | 使用 Windows API (`RegisterHotKey`) 注册全局快捷键，通过 QAbstractNativeEventFilter 捕获 WM_HOTKEY |
| `models.py` | 纯数据类 NoteInfo |

以下对每个模块的**本质职责、核心接口、依赖关系、生命周期边界**做具体定义，作为编码阶段的直接约束。

#### main.py — 进程入口

**本质职责：** 创建 QApplication 实例，实例化 App 主控对象并调用 run()。

```python
# 核心结构
def main() -> None:
    app = QApplication(sys.argv)
    controller = App(
        notes_dir=_APP_ROOT / "notes",
        config_path=_APP_ROOT / "config.json",
        theme_path=_APP_ROOT / "theme.json",
    )
    controller.run()
```

**关键点：**
- 项目根路径通过 `Path(__file__).resolve().parent` 自动确定，非硬编码
- 便签目录 `notes/`、配置文件路径均由 main.py 传入 App

**边界：** 不包含任何业务逻辑。

---

#### app.py — 应用生命周期控制器

**本质职责：**
1. 按固定顺序初始化各模块
2. 跨模块的信号-槽总装（wiring）
3. 管理应用启动和退出

**核心接口：**
```python
class App:
    def __init__(self, notes_dir, config_path, theme_path)
    def run(self) -> None            # 全流程：config加载 → 字体加载 → 窗口创建 → tray/热键注册 → 文件监听 → 显示窗口
    def _quit(self) -> None          # 逆序清理：停止监听 → 注销热键 → 隐藏托盘 → 退出事件循环
```

**初始化顺序：**
1. 设置 AppUserModelID（修正任务栏图标）
2. 加载 config.json + theme.json
3. 同步注册表自启状态
4. 加载 fonts/ 目录下的自定义字体
5. 创建 WallpaperWindow（注入 callbacks）
6. 创建 NotesManager + 连接信号
7. 创建 HotkeyManager + 连接信号
8. 设置窗口图标
9. 创建 TrayManager + 连接信号
10. 配置 `setQuitOnLastWindowClosed(False)`
11. 加载初始便签 + 启动文件监听
12. show() 窗口 + 注册热键（窗口显示后才注册，确保 HWND 稳定）

**信号-槽总装责任（由 __init__ 方法执行）：**
- `notes_manager.note_changed(filepath)` → `window.refresh_current_tab(filepath)`
- `notes_manager.note_added(filepath)` → `window.add_tab(filepath)`
- `notes_manager.note_deleted(filepath)` → `window.remove_tab(filepath)`
- `hotkey_manager.activated` → `window.bring_to_front_and_edit()`
- `tray.exit_requested` → `self._quit()`
- `tray.settings_requested` → `self._on_settings_requested()`
- `tray.edit_requested` → `window.bring_to_front_and_edit()`

**回调桥接（window → app → notes_manager）：**
```python
callbacks = {
    "on_save_content": self._on_save_content,
    "on_create_note": self._on_create_note,
    "on_delete_note": self._on_delete_note,
    "on_rename_note": self._on_rename_note,
}
```

**边界：** 不直接操作 UI 组件，不直接读写文件。仅做初始化编排和信号连接。

#### window.py — 桌面窗口管理器

**本质职责：**
1. 持有 QTabWidget（标签栏）+ 每个标签的 QStackedWidget（viewer/editor 双层）
2. 实现桌面层（HWND_BOTTOM）与置顶层（HWND_TOPMOST）的切换
3. 实现无边框窗口的拖拽移动（标签栏/⊕ 按钮区域长按拖拽）与边缘缩放（8px 检测）
4. 完成显示模式与编辑模式的双击/Enter/Esc 切换
5. WA_TranslucentBackground + WM_NCHITTEST 全区域鼠标事件
6. 空白区域滚轮转发（wheelEvent → 当前便签 viewer/editor）

**核心接口：**
```python
class WallpaperWindow(QWidget):
    def __init__(self, callbacks: dict, config: Config, theme: dict)
    def bring_to_front_and_edit(self) -> None   # 置顶 + 聚焦编辑框（被 hotkey/tray 触发）
    def return_to_desktop_layer(self) -> None    # 回到桌面层（编辑完毕调用）
    def refresh_current_tab(self, filepath: str) -> None  # 重新渲染当前标签
    def add_tab(self, filepath: str) -> None     # 新增标签页
    def remove_tab(self, filepath: str) -> None   # 移除标签页
    def apply_theme(self, theme: dict) -> None    # 应用新主题（QSS + pane边框 + 玻璃/发光/磨砂效果）
```

**窗口层级切换（Windows API，不用 setWindowFlags 避免闪烁）：**
```python
def _set_desktop_layer(self) -> None:
    ctypes.windll.user32.SetWindowPos(hwnd, _HWND_BOTTOM, ...)

def _set_topmost(self) -> None:
    ctypes.windll.user32.SetWindowPos(hwnd, _HWND_TOPMOST, ...)
```

**编辑模式切换逻辑：**
- 双击 / Enter → 切入编辑模式（QStackedWidget index 1）
- 三击（2 次 DblClick）→ 保存并退出编辑模式
- Esc → 保存并退出编辑模式 + 窗口回到桌面层
- 标签切出 → 自动保存上一个标签的编辑内容

**特效支持：**
- `TextGlowEffect(QGraphicsEffect)` — 文字辉光（box blur 缩小→放大）
- `FrostedNoiseWidget` — 磨砂噪点覆盖层（WA_TransparentForMouseEvents）
- 假毛玻璃 CSS — `_build_glass_qss()` 生成对角线渐变半透背景

**内容区边框：**
- 每个 QStackedWidget 通过 `setStyleSheet` 应用 `pane_border_color/width/radius`
- 上圆角为 0（紧贴标签栏），下圆角独立配置

**圆角实现：** 通过 `setMask(QRegion(QPainterPath))` 实现，因为 `WA_TranslucentBackground` 下 QSS border-radius 在 Windows 分层窗口中不生效。

**依赖：** config（theme）、notes_manager（文件操作）、renderer（MD→HTML）

**边界：** 不直接读写文件系统。不做文件格式转换。

**本质职责：**

#### settings.py — 设置对话框

**本质职责：**
1. 提供修改全局快捷键的 UI（CheckBox + ComboBox）
2. 提供修改 theme.json 中所有样式参数的 UI（颜色选择器、数值框、字体选单）
3. 字体管理：查看已添加字体 + 文件对话框添加 .ttf/.otf（自动复制到 fonts/ 并注册）
4. 提供 Apply 实时预览（不关闭对话框）
5. 通过 get_result() 返回新的快捷键设置和完整的样式字典

**核心接口：**
```python
class SettingsDialog(QDialog):
    applied = Signal(object)  # 点击「应用」时发出，携带当前 theme dict

    def __init__(
        self, current_modifiers, current_key, theme,
        autostart=False, fonts_dir=None, parent=None
    )

```

**依赖：** config（theme 数据，但不直接持久化）

**边界：**
- 纯 UI，无业务逻辑
- 不直接访问 config / hotkey / theme 的持久化模块
- 样式字段未在 UI 中展示的部分，从 theme 快照原样保留
- Apply 信号由 app.py 连接后执行持久化和刷新

#### notes_manager.py — 文件系统到便签列表的映射器

**本质职责：**
1. 维护 `notes/` 目录的实时镜像：`list[NoteInfo]` 与目录下的 `.md` 文件保持最终一致
2. 提供 CRUD 方法——直接操作文件系统
3. 启动 watchdog 监听目录变化，变化发生时发射信号（300ms 防抖）
4. 对上游屏蔽文件路径、监听器等实现细节

**核心接口：**
```python
@dataclass
class NoteInfo:
    filepath: str          # 完整路径
    filename: str          # 显示名（不含 .md 后缀）
    content: str           # 文件内容
    last_modified: float   # 时间戳

class NotesManager(QObject):
    # 信号
    note_changed = Signal(str)       # filepath
    note_added = Signal(str)         # filepath
    note_deleted = Signal(str)       # filepath

    def __init__(self, notes_dir: str | Path)
    def scan_all(self) -> list[NoteInfo]           # 启动时全量扫描
    def create(self, filename: str) -> NoteInfo     # 创建 .md 文件
    def delete(self, filepath: str) -> None         # 删除 .md 文件
    def rename(self, old_path: str, new_name: str) -> str  # 重命名，返回新路径
    def save_content(self, filepath: str, content: str) -> None
    def read_content(self, filepath: str) -> str
    def start_watching(self) -> None                # 启动 watchdog 监听
    def stop_watching(self) -> None                 # 停止监听
```

**文件变化处理（内部逻辑）：**
```
watchdog 事件 → 过滤（仅 .md + 300ms 防抖）→ 判断事件类型：
  → modified: 发射 note_changed
  → created:   发射 note_added
  → deleted:   发射 note_deleted
```

**边界：**
- 不关心文件内容格式（仅读写，不做解析）
- 不关心上游如何使用 NoteInfo
- 只操作 notes/ 目录

**本质职责：**
1. 创建 QSystemTrayIcon 并显示在系统托盘区

#### hotkey.py — 全局热键注册器

**本质职责：**
1. 使用 Windows API（`RegisterHotKey` + `WM_HOTKEY`）注册系统级热键
2. 热键触发时发射 activated 信号
3. 零额外依赖，仅依赖 ctypes

**核心接口：**
```python
class HotkeyManager(QObject):
    activated = Signal()                     # 快捷键被按下

    def __init__(self, modifiers: list[str], key: str)
    def register(self) -> bool               # 注册热键
    def unregister(self) -> None             # 注销热键
    def rebind(self, modifiers: list[str], key: str) -> bool  # 重绑定
```

**实现机制：** 通过 `QAbstractNativeEventFilter` 捕获 `WM_HOTKEY` 消息，解析 MSG 结构体后发射 activated 信号。使用 `MOD_NOREPEAT` 防重复触发。

**边界：** 只做「检测到快捷键 → 发信号」这一件事。

## 3. UI 架构

### 3.1 布局结构

```
主窗口 (WallpaperWindow: QWidget)
│
├── 标签栏: QTabWidget
│   ├── 每个标签页 = 一个 .md 文件
│   ├── 右侧内嵌 ⊕ 按钮（QPushButton，setParent(tabBar)，move() 定位）
│   ├── 右键菜单（重命名/删除）
│   └── 样式由 theme.json 控制
│
└── 内容区: QStackedWidget（每个标签页一个）
    ├── Index 0 — QTextBrowser（显示模式）
    │   渲染后的 Markdown 效果，美观展示，带可选文字辉光 + 假毛玻璃
    │
    └── Index 1 — QPlainTextEdit（编辑模式）
        原始 Markdown 文本，可编辑，带可选文字辉光
```

### 3.2 模式切换

```
显示模式 (QTextBrowser)  ←──────────→  编辑模式 (QPlainTextEdit)
     ↑                                        ↑
  双击/Enter 内容区                       Esc / 三击
     │                                        │
     └──── QStackedWidget.setCurrentIndex() ──┘
```

### 3.3 窗口行为

| 行为 | 实现方式 |
|------|----------|
| 无标题栏 | `setWindowFlags(Qt.FramelessWindowHint)` |
| 桌面层 | `SetWindowPos(hwnd, HWND_BOTTOM, ...)` 通过 ctypes |
| 拖拽移动 | 标签栏/⊕ 按钮区域 MousePress → Move（距离阈值 → 拖拽模式） |
| 调整大小 | 8px 边缘检测 + mouseMoveEvent + SetCursor + resize |
| 置顶（快捷键/托盘） | `SetWindowPos(hwnd, HWND_TOPMOST, ...)` + AttachThreadInput 技术（穿透 Windows 前台锁定） |
| 返回桌面层（Esc） | 保存内容 → 切回显示模式 → SetWindowPos HWND_BOTTOM |
| 鼠标穿透 | WA_TranslucentBackground + nativeEvent(WM_NCHITTEST) 全区域返回 HTCLIENT |
| 空白区滚动 | wheelEvent → sendEvent 到当前便签 viewer/editor viewport |

### 6.1 操作与映射解耦

```

      文件系统（notes/ 目录）
```

| 文件 | 用途 | 用户是否常改 |
|------|------|------------|
| `config.json` | 功能配置（窗口位置/快捷键/开机自启） | 一般不常改 |
| `theme.json` | 样式配置（颜色/字体/透明度/圆角/玻璃/发光/磨砂） | 可自由修改换皮肤 |

### 6.3 UI 组件独立

所有 UI 相关代码集中在 `window.py` + `ui_components.py` + `settings.py`，与后端业务逻辑解耦。未来如果 QTabWidget 不满足需求，只需修改 `ui_components.py` 中的组件实现，后端完全不受影响。

### 6.4 IME 输入法候选框兼容设计（2026-05-21 新增）

**问题背景：**
编辑器中输入中文拼音时，IME 候选框出现在文字约 3/4 高度位置（
而非光标底部），遮挡正在输入的文字。

**初步诊断（无效）：**
最初怀疑是 `WA_TranslucentBackground`（分层窗口）+ viewport 上的 `QGraphicsEffect`（文字辉光）导致 Qt 的 `inputMethodQuery()` 坐标映射异常。新建了 `IMEFriendlyPlainTextEdit` 子类重写 `inputMethodQuery()`，将 viewport 坐标映射回 editor 坐标——但用户实测无效。

**真实根因：**
QSS `padding: 12px` 使 editor 内部的 viewport 偏移了 (12,12)。
当 Windows TSF（Text Services Framework）通过 Qt 查询游标位置时，
Qt 内部用 `editor->mapToGlobal(viewport坐标)` 映射，
但坐标被识别为 editor 自身坐标（未补偿 viewport 偏移量），
导致 IME 候选框偏左上 12px。

**修复方案：容器包裹法（2026-05-21 实施）**
```
┌── QStackedWidget (index 1) ──────────────────────┐
│ ┌── QWidget (editor_container) ─────────────────┐ │
│ │  border-bottom-left/right-radius: {pane_br}px │ │
│ │  background-color: {editor_bg}                │ │
│ │                                                │ │
│ │  ←{12px margin}→ ┌── QPlainTextEdit ──┐ ←{12px}→ │
│ │                  │ 无 padding          │         │
│ │                  │ 无 border-radius    │         │
│ │                  │ 无 QGraphicsEffect  │         │
│ │                  └────────────────────┘         │
│ │                   ↑ editor 裸奔状态              │
│ └────────────────────────────────────────────────┘ │
│   ↑ 容器用 layout.setContentsMargins 提供视觉间距   │
└──────────────────────────────────────────────────┘
```

**核心变更：**
1. 删除 `IMEFriendlyPlainTextEdit` 子类（inputMethodQuery 覆写无效）
2. editor 改用裸 `QPlainTextEdit`，QSS 中去掉 `padding` 和 `border-radius`
3. 外包 `QWidget` 容器，用 `QVBoxLayout.setContentsMargins(ph, pv, ph, pv)` 提供视觉间距
4. 容器 `setObjectName("editor_container")` 作为查找标识
5. 容器 QSS 设 `border-bottom-left/right-radius: {pane_br}px` 维持 UI 圆角外观

**关键位置：**
- 容器创建：`_create_tab_content()`（约第 696 行）
- 主题同步：`apply_theme()`（约第 546 行），同时更新容器背景色、margins、border-radius
- 编辑器定位：所有原来 `stack.widget(1)` 直接获取 editor 的地方，改为 `stack.widget(1).findChild(QPlainTextEdit)`

**设计约束（未来修改必须遵守）：**
| 约束 | 原因 |
|------|------|
| editor 的 QSS 不能有 `padding` | 否则 IME 候选框偏移复现 |
| editor 不能应用 `QGraphicsEffect`（包括文字辉光） | 辉光创建独立渲染层，同样破坏 TSF 坐标链路 |
| `viewport.setAutoFillBackground(False)` 必须保留 | 透出 QStackedWidget 的 pane 边框 |
| 所有 `stack.widget(1)` 的直接访问都必须改为通过 findChild | widget(1) 返回的是容器而非 editor |
| `apply_theme` 必须同时同步容器的背景色 + margins + border-radius | 否则容器状态与 editor QSS 脱节 |
| 容器的 border-radius 必须与 QStackedWidget 的 pane_border_radius 一致 | 否则底部圆角外观出现断层 |

**验证方式：**
用任何支持 IME 的输入法（微软拼音、搜狗等）在编辑器中输入文字，
确认候选框出现在光标正下方。

### 6.6 编辑/预览模式切换时的滚动位置同步（2026-05-21 新增）

**问题背景：**
双击进入编辑、Esc 返回预览时，阅览器和编辑器都有各自的滚动条，切换后滚动位置归零，用户需要手动重新滚动到之前的阅读/编辑位置。

**方案选型：百分比锚定**

编辑器和阅览器持有**完全不同的 QTextDocument 树**：

| widget | 内容 | 行高 | 字号 | 文档结构 |
|--------|------|------|------|---------|
| QPlainTextEdit（编辑） | 原始 Markdown 文本 | 等宽字体行高 | editor_font_size | 纯文本段落 |
| QTextBrowser（阅览） | 渲染后的 HTML | 普通字体行高 + 标题/列表等 HTML 块级元素 | content_font_size + heading_font_size | `<h1>`、`<p>`、`<ul>` 等 HTML 元素树 |

两种文档树的 block/character 位置无法跨 widget 对应（编辑器的 `# 标题` 是 1 行，阅览器的 `<h1>标题</h1>` 是 1 个占用不同像素高度的 HTML 块）。因此 **block/character 锚定不可行**，百分比（`scrollbar.value() / scrollbar.maximum()`）是唯一的通用度量。

**核心数据结构 & 方法：**

```python
@staticmethod
def _get_scroll_pct(widget) -> float:
    """读取垂直滚动百分比（0.0 ~ 1.0）。"""
    sb = widget.verticalScrollBar()
    max_val = sb.maximum()
    return sb.value() / max_val if max_val > 0 else 0.0

@staticmethod
def _set_scroll_pct(widget, pct: float) -> None:
    """按百分比设置同步滚动位置。"""
    sb = widget.verticalScrollBar()
    max_val = sb.maximum()
    if max_val > 0:
        widget.setUpdatesEnabled(False)  # 关绘制避免闪烁
        sb.setValue(round(pct * max_val))
        widget.setUpdatesEnabled(True)
```

**关键设计细节：**

| 方面 | 选型 | 理由 |
|------|------|------|
| `round()` 而非 `int()` | `round()` | `int()` 单向截断，快速切换时漂移单方向积累；`round()` 四舍五入使误差双向平均，长期不累积 |
| 同步设值而非 `QTimer.singleShot(0)` | 同步 + `setUpdatesEnabled` | Timer 导致 scroll 恢复与 layout 结算之间的时序漏洞，是偶发"回跳"的根因 |
| `_switch_edit` 中移除 `_ensure_viewer_latest()` | 无需重绘 viewer | editor 内容从文件读取，不依赖 viewer 状态；重绘只会引入滚动伪影 |

**四个滚动同步入口：**

| 入口 | 读自 | 写入 | 触发时机 |
|------|------|------|---------|
| `_switch_edit` | viewer (阅览器) | editor (编辑器) | 双击/Enter 进入编辑 |
| `_save_and_switch_view` | editor (编辑器) | viewer (阅览器) | Esc 保存并回到预览 |
| `_on_tab_changed` | editor (编辑器) | viewer (阅览器) | 切标签时保存前一个 tab |
| `refresh_current_tab` | viewer (阅览器) | viewer (阅览器) | watchdog 检测到外部文件变更 |

**watchdog 防冲撞机制：**

用户按 Esc 时，保存文件 → viewer.setHtml 渲染 → 恢复滚动。但 watchdog（`notes_manager.py` 的 PollingObserver）~1 秒后也会检测到文件变更，触发 `refresh_current_tab` → 再次 viewer.setHtml → 再次恢复滚动。两次恢复的 `round()` 误差累积 → 用户感知的"回正"或"漂移"。

解决方案：**`_just_saved` 标记 + 刷新式单一定时器**。

```python
def _mark_just_saved(self, fp: str) -> None:
    """标记文件为己保存，刷新 3 秒看门狗——连续保存时窗口自动续期。"""
    if not hasattr(self, '_just_saved'):
        self._just_saved: set[str] = set()
    self._just_saved.add(fp)
    if hasattr(self, '_just_saved_timer') and self._just_saved_timer is not None:
        self._just_saved_timer.stop()
    self._just_saved_timer = QTimer.singleShot(3000, self._clear_just_saved)

def _clear_just_saved(self) -> None:
    self._just_saved.clear()
    self._just_saved_timer = None
```

每次保存前标记文件路径，watchdog 的 `refresh_current_tab` 检查该路径是否在标记中——如果在则跳过。标记通过**单一定时器刷新**管理：每次保存时重启定时器，确保仅在用户真正停止操作 3 秒后才清除，避免堆叠式多定时器导致的误清除窗口。

**已知的稳定性风险（设计阶段已识别）：**

1. **viewer → editor 跨坐标系转换**：两个 widget 的 scrollbar range 不同（不同字体/文档结构），相同的百分比对应不同的文本段落位置——这是百分比方案的固有特性，不是 bug
2. **watchdog 延迟事件**：文件写入可能触发多个 OS 级 modification 事件，经 300ms debounce 和跨线程信号排队后，可能刚好在标记清除后到达——单定时器刷新已将概率降为理论可能
3. **编辑器容器化后 editor 定位**：IME 修复改用容器包裹后，所有 `stack.widget(1)` 直接取 editor 的代码需改为 `findChild(QPlainTextEdit)`——`_set_scroll_pct` 调用处已全部适配

- `_get_scroll_pct`：~ 第 818 行
